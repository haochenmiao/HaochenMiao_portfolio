Three interactions worth trying

01
Switch the indicator
The left menu swaps which of the six variables drives the map. Height and color update together — every tract re-extrudes.
02
Click a tract
Any tract pops a card with its FIPS, name, the active indicator's value, and a marker showing where that value sits in the statewide distribution.
03
Search by city
The search box uses a Maps-of-World city-coordinate CSV to fly the camera to a place. Useful for comparing urban and rural tracts side by side.

How the encoding works

One value, two channels

Each indicator is min-max normalized to a 0–1 scale so values are comparable across variables that live on very different ranges (low birth weight runs 0–15%, unaffordable housing runs 10–75%+).

v_n = (v − v_min) / (v_max − v_min)

That single normalized number then drives both the polygon's height (extrusion in meters) and its color stop on a purple ramp. Height and color agree — a short dim tract reads "low" from both cues, a tall bright tract reads "high."

Why clip to land

Census tract geometries extend into Puget Sound and the Pacific. Without clipping, coastal tracts render as enormous water polygons that pull the eye away from populated areas. The build clips every tract to the Census cartographic land boundary before rendering.

Honest limits

  • No statistical inference. The map describes spatial patterns in six normalized variables — it does not claim causation, model outcomes, or forecast change.
  • Vintages vary. The six indicators were pulled from the Washington Geospatial Open Data Portal at different times. A rerun of the build would need to re-align them.
  • Proxies, not outcomes. "People of color" and "unaffordable housing" are structural proxies for equity, not measurements of lived experience. Read alongside, not instead of, community voice.
  • Known README issue. The repository's README links the Unemployment dataset to a page that actually lists toxic releases from facilities. The map itself uses the correct unemployment file — the README link is wrong.
  • Mapbox token required. The 3D view loads a token at runtime; a fork needs its own token to serve the map.

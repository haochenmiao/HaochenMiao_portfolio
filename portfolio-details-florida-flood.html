Why Cape Coral

Cape Coral sits on 400+ miles of saltwater canal — more than any other city on earth. Its road grid was platted in the 1950s before FEMA flood zones existed, so neighborhoods, schools, and fire stations now sit inside Zone AE by accident of history, not by current policy choice. The city also has a disproportionately elderly population and uneven access to private evacuation resources.

That makes it a worked example for the question this atlas asks: when risk and vulnerability stack in the same place, where does the next dollar of mitigation go? The CDC's Social Vulnerability Index and FEMA's National Flood Hazard Layer each answer half of that question. This project overlays them in one view so a planner, an emergency manager, or a community advocate can see the full picture in one map.

Pipeline

The data engineering is light but reproducible — three stages from public API to interactive map.

The FIPS join

The notebook geospatial_fips_processor.ipynb reads the CDC SVI table (keyed by 11-digit FIPS tract codes) and the Lee County census tract GeoJSON (keyed on GEOID with Florida 12-prefix). It normalizes both to zero-padded strings, joins on the shared key, and emits a single GeoJSON with every SVI subscore attached to tract geometry. This is the one place the project moves beyond "load a layer" into actual data wrangling, and it's what makes the SVI × flood overlay possible.

Why static GitHub Pages

No server, no API keys embedded (Mapbox token loads at runtime from a user-supplied env), no bundler. A planner can fork the repo, swap in their city's FEMA REST endpoint and SVI tract file, and have the same atlas running in an afternoon.

Honest limits

  • No forecast model. This is overlay and visualization, not predictive flood modeling. Zone AE itself is FEMA's 1% annual chance estimate, not a Cape-Coral-specific storm-surge simulation.
  • SVI vintage is 2020. Post-Hurricane Ian (2022) demographic shifts in Cape Coral are not reflected. A production version would rebuild on CDC's next SVI release.
  • No field validation of infrastructure points. School and fire-station locations come from county open data and were not re-verified on the ground.
  • Static tiles. The maps don't update when FEMA republishes NFHL — a rerun of the pipeline is required.
  • Mapbox token required for the 3D view. The 2D Leaflet view works without one.
